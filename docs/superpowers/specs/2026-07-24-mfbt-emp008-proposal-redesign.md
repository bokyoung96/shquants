# MFBT EMP008 멀티팩터 제안서 재설계

## 커뮤니케이션 목표

이 제안서를 본 운용·상품·마케팅 담당자는 EMP008이 단순 팩터 합산 전략이 아니라, 여섯 개 투자 질문을 벤치마크 대비 기대수익으로 변환하고 위험 제약 아래 최종 비중으로 구현하는 체계라는 점을 이해해야 한다.

## 대상과 용도

- 대상: 신한자산운용 내부 운용·상품·마케팅 담당자 및 기관 고객
- 용도: 전략 구조 설명, 팩터 산정 기준 검토, 최적화 결과 해석
- 핵심 결론: EMP008의 결과는 종목 선호 순위가 아니라 KOSPI200 대비 상대 비중이며, 삼성전자·SK하이닉스의 반대 방향 액티브 비중은 시장대표주 쏠림과 업종중립 제약, 상대 팩터 점수의 결합으로 발생한다.

## 정확성 원칙

- 사용자가 제공한 산식은 화면에서 `제안 산정 방식`으로 표기한다.
- 현재 코드 구현과 다른 항목을 이미 구현된 사실처럼 표현하지 않는다.
- 현재 구현과 제공안의 주요 차이는 다음과 같다.
  - 배당: 현재 구현은 DPS TTM/주가이며 3년 연속 증액 프리미엄은 미반영이다.
  - 주가모멘텀: 현재 구현은 현재가/252일 고가의 연속값이며, 제공안의 80% 기준 0/1 방식과 다르다.
- 이익모멘텀의 저기저 예외, FCF/TEV, 업종 상대 개인수급, 지수 비중 10% 이상 종목의 시가총액 중립화는 코드 구현과 정합적이다.
- 2026-06-01 기준 저장 산출물에서는 삼성전자 액티브 비중이 약 -0.046%, SK하이닉스가 약 +0.066%다. 이는 예시 시점의 결과로만 사용하고 일반화하지 않는다.
- 전체 43개 월 중 두 종목의 액티브 방향이 반대였던 달은 31개다. `SK하이닉스 롱/삼성전자 언더` 16회, `삼성전자 롱/SK하이닉스 언더` 15회로 방향이 거의 대칭이므로 고정된 종목 전망이 아니라 최적화 구조의 결과로 해석한다.

## 시각 시스템

- 기준: 사용자 제공 제안서의 흰색 바탕, 상단 `운용전략`, 시안색 플러스 기호, 얇은 구분선, 하단 신한자산운용 푸터를 유지한다.
- 본문: 카드 그리드를 제거하고, 슬라이드마다 하나의 대형 데이터 비주얼을 중심으로 구성한다.
- 색상: 딥 네이비, 로열 블루, 신한 계열 시안, 쿨 그레이만 사용한다. 빨강·초록 매매 색상과 과도한 그라데이션은 사용하지 않는다.
- 이미지: `backtesting/strategies/emp008/assets/design-v2/`의 네 가지 생성 이미지를 각각 한 번만 사용한다.
- 타이포그래피: 제목 26~30pt, 핵심 문장 20~24pt, 본문 14~17pt를 기본으로 하되 원본 제안서의 정보 밀도를 존중한다.
- 문장: 슬라이드 제목은 주제를 나열하지 않고 해당 페이지의 결론을 말한다.

## 스토리라인과 슬라이드 구성

### 1. 여섯 개 투자 질문이 하나의 액티브 비중으로 수렴한다

- 역할: EMP008의 전체 구조를 한 문장으로 설명한다.
- 핵심 문장: 가격·이익·배당·수급·가치·규모의 서로 다른 질문이 최종적으로 BM 대비 액티브 비중 하나로 변환된다.
- 비주얼: `01-signal-to-active-weight.png`를 우측과 하단 중심으로 배치한다.
- 본문: 여섯 팩터명을 짧은 질문 형태로만 제시한다.

### 2. 여섯 팩터는 서로 다른 실패 가능성을 보완한다

- 역할: 왜 멀티팩터인지 설명한다.
- 핵심 문장: 한 팩터의 오판을 다른 정보원이 상쇄하도록 가격·펀더멘털·수급 데이터를 함께 사용한다.
- 비주얼: `02-factor-architecture.png`를 중앙의 주 시각물로 사용한다.
- 팩터 그룹:
  - 가격·구조: 주가모멘텀, 시가총액
  - 펀더멘털: 이익모멘텀, 배당수익률, 밸류
  - 수급: 업종 상대 개인수급

### 3. 배당·규모·가격은 함정을 피하도록 산정한다

- 역할: 제안 산정 방식 1/2를 설명한다.
- 레이아웃: 왼쪽에 산식, 오른쪽에 채택 사유를 두는 세 개의 가로 행으로 구성한다. 반복 카드 대신 얇은 구분선과 큰 팩터명을 사용한다.
- 배당수익률:
  - 산정: 배당수익률 Q1~Q5 점수 + 3년 연속 배당액 증액 프리미엄
  - 사유: 주가 하락 때문에 높아진 단순 배당수익률을 좋은 신호로 오인하지 않기 위함
- 시가총액:
  - 산정: 기존 점수 유지, 지수 비중 10% 이상 종목은 Neutral 고정
  - 사유: 한국 시장의 대형주 쏠림이 규모 팩터를 지배하지 않도록 함
- 주가모멘텀:
  - 산정: 현재가/52주 신고가가 80%를 넘으면 1, 아니면 0
  - 사유: 횡단면 분위보다 실제 신고가 접근 여부가 강한 상승 종목을 더 직접적으로 식별함

### 4. 이익·가치·수급은 경제적 의미와 극단값 통제를 함께 갖는다

- 역할: 제안 산정 방식 2/2를 설명한다.
- 이익모멘텀:
  - 산정: 영업이익 12MF의 1개월 상향률을 분위 점수화
  - 예외: 분모는 절대값을 사용하고 극단값을 조정한다. 현재 영업이익이 1,000억원 미만이면서 성장률이 50%를 초과하면 배제한다.
  - 사유: 저기저 효과로 작은 기업의 이익 모멘텀이 과대평가되는 것을 막는다.
- 밸류:
  - 산정: FCF/TEV 분위, TEV=시가총액+이자발생부채-당좌자산
  - 사유: 주주 귀속 현금흐름이 크고 기업가치가 낮은 종목을 포착한다.
- 수급:
  - 산정: 252일 누적 개인수급에서 업종 평균을 차감한 뒤 부호를 반전해 업종별 점수를 종목에 배분한다.
  - 사유: 개별 종목 노이즈보다 업종 단위 자금 흐름이 지속적이며 해석 가능하다.

### 5. 최적화는 기대 알파를 위험 예산 안의 비중으로 바꾼다

- 역할: 팩터 점수와 최종 비중 사이의 연결을 설명한다.
- 비주얼: `03-risk-optimization.png`를 중앙 주 시각물로 사용한다.
- 흐름: 팩터 익스포저 → 최근 36개월 팩터 수익률 평균 → 기대 알파 → 팩터·고유위험 공분산 → 목표 비중
- 제약:
  - 액티브 비중 합계 0
  - 업종 액티브 익스포저 0
  - 연환산 추적오차 70bp
  - 최종 종목 비중 0 이상

### 6. 삼전·닉스 반대 포지션은 상대가치 표현이지 절대 숏이 아니다

- 역할: 사용자가 제기한 반복적인 삼성전자·SK하이닉스 롱숏 현상을 설명한다.
- 비주얼: `04-semiconductor-active-tilt.png`를 전체 폭으로 사용하고, 기준선에 BM, 위·아래 경로에 두 종목의 액티브 방향을 표시한다.
- 원인:
  1. 두 종목은 같은 업종 안에서 지수 비중이 크기 때문에 업종중립 제약이 종목 간 상대 포지션으로 표현되기 쉽다.
  2. 시가총액 팩터는 지수 비중 10% 이상 종목에서 중립화되어 규모 차이보다 나머지 다섯 팩터의 상대점수가 더 중요해진다.
  3. 제한된 추적오차 안에서 효율적으로 알파를 표현하려면 유동성이 높고 BM 비중이 큰 두 종목의 반대 방향 조정이 최적화에 유리할 수 있다.
- 실증 근거: 43개 월 중 반대 방향은 31개 월이며, 방향은 16회 대 15회로 거의 대칭이다. 따라서 이 패턴은 지속적인 삼성전자 또는 SK하이닉스 전망이 아니라 상대가치 포지션이다.
- 최근 해석: 2026-06-01의 36개월 기대 팩터 알파 단순합은 삼성전자가 더 높았지만 최종 액티브 비중은 삼성전자 언더, SK하이닉스 오버였다. 팩터 점수만으로 방향을 설명할 수 없고 공분산과 제약조건이 최종 배분을 결정한다는 사례로 사용한다.
- 해석 주의: 음의 액티브 비중은 실제 공매도가 아니라 BM보다 덜 보유한다는 뜻이다. 방향은 월별 신호에 따라 바뀐다.
- 예시: 2026-06-01 산출물은 삼성전자 -0.046%, SK하이닉스 +0.066% 액티브 비중이다.

## 검증 기준

- 모든 슬라이드를 PNG로 렌더링하고 몽타주와 원본 크기에서 확인한다.
- 제목 줄바꿈, 본문 잘림, 객체 겹침, 푸터·페이지 번호 불일치를 제거한다.
- 제공 산정안과 현재 구현을 혼동하는 문구가 없는지 검토한다.
- 삼성전자·SK하이닉스 수치는 저장된 `active_weights.parquet`의 최신 행과 일치해야 한다.
- `slides_test.py`와 레이아웃 JSON 검사를 통과해야 한다.
