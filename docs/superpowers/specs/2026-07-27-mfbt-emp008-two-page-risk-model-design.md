# MFBT EMP008 2페이지 제안서 개편 설계

## 커뮤니케이션 목표

기관투자자가 복잡한 수식 없이 다음 두 가지를 이해하도록 한다.

1. EMP008이 팩터를 발굴·검증하고 종목별 기대수익률로 변환하는 과정
2. 포트폴리오 최적화에 필요한 기대수익률과 분산·공분산을 Barra형 팩터 모형으로 추정하는 과정

자료의 목적은 모델의 수익 창출 논리를 설명하고 위험 추정 체계에 대한 신뢰를 형성하는 것이다. 감성적 문구나 투자 권유성 메시지는 사용하지 않는다.

## 범위

- 편집 대상: `backtesting/strategies/emp008/제안서_멀티팩터모델.pptx`
- 1페이지는 기존 3단 구성과 내용을 유지하면서 시각적 위계와 정렬을 현대화한다.
- 2페이지에는 Barra형 위험모형을 이용한 기대수익률·공분산 추정과 최적화 흐름을 추가한다.
- 기존 신한자산운용의 네이비·블루·라이트블루, 상단 제목 체계, 하단 브랜드 요소를 유지한다.
- CAPM 설명은 포함하지 않는다.
- 복잡한 수식, 성과 수치, 검증되지 않은 사례, 감성적 카피는 포함하지 않는다.

## 1페이지 설계

### 역할

팩터 아이디어가 연구와 검증을 거쳐 종목별 기대수익률로 변환되는 과정을 설명한다.

### 구조

원본의 `Research → Test & Monitoring → Quant Portfolio 구성` 가로 3단 구조를 유지한다.

1. **Research**
   - 기존 팩터 후보군과 `팩터 Clustering & Develop` 흐름을 유지한다.
   - Value, Size, Momentum, Quality, Investment, Low Risk, Accruals 등 원본의 연구 풀을 보여준다.
2. **Test & Monitoring**
   - 현재 EMP008에서 사용하는 여섯 팩터를 명확하게 구분한다.
   - 가치, 규모, 가격 모멘텀, 이익 모멘텀, 배당수익률, 개인 수급
   - 유의성, 중복성, 안정성, 데이터 품질을 검증한다는 의미는 짧은 문구로 유지한다.
3. **Quant Portfolio 구성**
   - 신한 멀티팩터 모델
   - 팩터별 기대수익률 추정
   - 종목별 기대수익률 산출
   - 2페이지의 위험 추정·최적화 단계로 연결

### 시각 개편

- 원본의 네이비 상단 바와 세 개의 단계 구성을 보존한다.
- 반복되는 작은 박스와 긴 설명을 줄이고, 단계명과 핵심 산출물을 우선 읽히게 한다.
- 동일한 의미의 항목은 정렬과 간격으로 묶고 장식적 카드나 대시보드형 UI는 추가하지 않는다.
- 하단 설명 영역은 다음 세 가지 운용 원칙으로 축약한다.
  - 설명 가능한 팩터
  - 중복을 줄인 안정적 조합
  - 데이터 품질과 지속성 검증

## 2페이지 설계

### 역할

포트폴리오 최적화의 핵심 입력값인 종목별 기대수익률과 종목 간 분산·공분산을 Barra형 팩터 모형으로 추정하는 과정을 설명한다.

### 제목

`Barra Risk Model 기반 기대수익률·공분산 추정 및 포트폴리오 최적화`

### 흐름

1. **입력 데이터**
   - 종목별 팩터 노출도
   - 과거 종목 수익률
2. **팩터 수익률 추정**
   - 월별 횡단면 회귀로 팩터 수익률과 종목 고유 수익률을 분리한다.
3. **기대수익률 추정**
   - 최근 36개월 평균 팩터 수익률과 종목별 팩터 노출도를 결합한다.
   - 결과는 최적화에 투입되는 종목별 기대수익률이다.
4. **분산·공분산 추정**
   - 팩터 수익률의 공분산과 종목 고유 위험을 결합한다.
   - 결과는 최적화에 투입되는 종목 공분산 행렬이다.
5. **포트폴리오 최적화**
   - 종목별 기대수익률과 공분산 행렬을 핵심 입력값으로 사용한다.
   - 벤치마크 대비 액티브 비중 합계 0, 업종 중립, 추적오차 한도, 최종 비중 0 이상 등의 현재 EMP008 제약조건을 반영한다.
   - 결과는 종목별 최적 비중이다.

### 시각 구조

- 왼쪽의 입력 데이터에서 중앙의 팩터 수익률 추정으로 연결한다.
- 중앙에서 기대수익률 추정과 분산·공분산 추정의 두 갈래로 분기한다.
- 두 결과를 오른쪽의 포트폴리오 최적화 단계에서 다시 합친다.
- 수식 대신 단계명, 입력값, 산출물을 짧은 문장으로 표시한다.
- 기대수익률과 공분산 행렬은 동일한 시각적 무게로 배치해 두 값 모두 필수 입력임을 보여준다.

## 템플릿 및 색상 원칙

- 기존 PPTX를 유일한 시각적 템플릿으로 사용한다.
- 네이비를 구조와 제목에, 블루와 라이트블루를 단계 구분에 사용한다.
- 기존 자료에 없는 새로운 주조색이나 과도한 그라데이션은 추가하지 않는다.
- 강조색은 기존 팔레트 안에서만 제한적으로 사용한다.
- 원본의 글꼴, 글자 크기 체계, 여백, 상단 제목, 하단 페이지·브랜드 요소를 우선 보존한다.

## 검증 기준

- 1페이지가 원본의 3단 흐름과 신한 브랜드를 유지한다.
- 2페이지가 기대수익률과 분산·공분산을 최적화의 두 핵심 입력값으로 명확히 보여준다.
- CAPM, 감성적 카피, 복잡한 수식이 남아 있지 않다.
- 모든 EMP008 설명은 현재 코드와 README의 구현과 일치한다.
- 모든 최종 슬라이드를 렌더링해 겹침, 잘림, 줄바꿈, 빈 플레이스홀더를 확인한다.
- 템플릿 충실도 검사와 슬라이드 오버플로 검사를 통과한다.
