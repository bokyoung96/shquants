# EMP008 모델 비교 리포트 설계

## 목적

`mfbt`와 `origin` EMP008 결과를 각각 `수정EMP008`, `기존EMP008`로 표시하고, 동일 기간과 동일 거래비용 조건에서 성과·위험·연도별 경로·수익률 분포·최근 포지션을 비교한다. 리포트는 차이가 얼마나 발생했는지만 보여주지 않고, 설정·보유종목·섹터 및 팩터 노출·실현 기여도로 차이의 원인을 설명해야 한다.

## 접근법

1. **독립형 EMP008 비교 리포트 모듈 — 채택**
   - 기존 target weights와 백테스트 엔진을 재사용한다.
   - 비교 전용 분석과 시각화만 새 모듈에 둔다.
   - 기존 범용 리포팅 시스템의 계약을 바꾸지 않아 변경 범위가 좁다.
2. 범용 reporting 패키지의 comparison 형식 확장
   - 다른 전략에도 재사용할 수 있지만 EMP008의 팩터·위험설정 설명을 일반화하는 비용이 크다.
3. 일회성 분석 스크립트
   - 가장 빠르지만 재실행, 입력 검증, 회귀 테스트가 약해 최종 산출물 생성기로 부적합하다.

## 입력과 비교 기준

- 수정 모델 입력: `mfbt` run root 또는 해당 `target_weights.csv`.
- 기존 모델 입력: `origin` run root 또는 해당 `target_weights.csv`.
- 모델 표시는 리포트에서만 `수정EMP008`, `기존EMP008`로 변환한다. 내부 factor-set ID는 변경하지 않는다.
- 두 target weights의 공통 리밸런싱 구간만 사용한다.
- 양쪽을 동일하게 다시 백테스트한다.
  - 체결: 종가
  - 초기자본: 100,000,000원
  - 소수점 수량 허용
  - 수수료: 0.02%
  - 매도세: 0.15%
  - 슬리피지: 0.05%
- 비용 반영 성과를 본문 기준으로 사용하고 gross 성과 및 비용 차감 효과도 표에 병기한다.

## 산출물

최종 디렉터리는 `results/emp008_model_comparison/<end-date>/`로 한다.

- `report.html`: 한국어 단일 비교 리포트. 상대경로로 아래 그림과 표를 포함한다.
- `report.json`: 입력, 조건, 핵심 지표, 자동 해석 근거의 기계 판독본.
- `metrics.csv`: gross/net 모델별 성과지표.
- `yearly_returns.csv`: 연도별 수익률과 모델 간 차이.
- `latest_positions.csv`: 최신 목표비중, 비중 차이, 편입 상태.
- `latest_sector_exposure.csv`: 최신 섹터 비중과 차이.
- `latest_factor_exposure.csv`: 최신 공통 진단 팩터 노출과 차이.
- `performance_gap_contributors.csv`: 모델 간 성과 차이의 주요 종목별 기여 근사치.
- `figures/cumulative_mdd.png`
- `figures/yearly_cumulative_subplots.png`
- `figures/return_distribution.png`
- `figures/latest_positions.png`

## 리포트 구성

1. **요약**
   - 비교 기간과 비용조건.
   - CAGR, 누적수익률, 연환산 변동성, Sharpe, MDD, 양의 일/월 비율, 평균 회전율.
   - 수정EMP008과 기존EMP008의 지표 차이.
2. **누적성과와 MDD**
   - 상단: 두 net NAV를 100으로 정규화해 비교.
   - 하단: 두 drawdown을 동일 축에 표시하고 각 MDD를 주석으로 표시.
3. **연도별 누적성과**
   - 연도별 subplot에서 첫 공통 거래일을 100으로 재기준화.
   - 동일 색상 규칙을 모든 그림에 유지한다.
4. **수익률 분포**
   - 공통 bin의 일간수익률 histogram과 분포 요약을 함께 표시.
   - 평균, 중위수, 하위 5%, 상위 95%, 왜도 및 꼬리손실을 표에 제시.
5. **최근 포지션**
   - 최신 공통 리밸런싱 날짜의 상위 비중 및 절대 비중 차이 종목.
   - 공통편입, 수정EMP008 전용, 기존EMP008 전용 상태를 표시.
   - 겹치는 비중 합계와 두 모델 간 active share를 계산.
6. **차이가 발생한 이유**
   - 구조적 이유: factor set, 위험모형, 추적오차 제약 차이를 run metadata에서 읽어 명시.
   - 최신 포지션 이유: 섹터 및 진단 팩터의 가중 노출 차이와 가장 큰 비중 차이를 제시.
   - 실현 성과 이유: 각 리밸런싱 구간의 시작 비중과 종목수익률로 모델 간 종목별 기여 차이를 계산해 상·하위 기여자를 제시.
   - 거래비용 효과: gross와 net의 최종 성과 차이를 별도로 분리한다.
   - 설명은 수치에서 결정적으로 생성하며 근거 없는 인과표현을 사용하지 않는다.

## 시각 디자인

- 흰 배경, 얇은 회색 grid, 불필요한 테두리 제거.
- `수정EMP008`: 짙은 청록색, `기존EMP008`: 중립적인 회색/남색.
- 핵심 차이만 주황색으로 강조.
- 제목은 결론형 문장, 범례와 단위는 간결하게 유지.
- 한국어 글꼴은 시스템 가용 폰트를 순서대로 fallback하고 minus sign 깨짐을 방지한다.
- 그림은 160 DPI PNG로 저장하며 HTML에서도 과도하게 확대되지 않도록 한다.

## 데이터 흐름과 경계

1. CLI가 두 run root와 출력 경로를 검증한다.
2. target weights와 run metadata를 읽어 공통 기간을 결정한다.
3. 동일 비용/실행조건의 gross 및 net 백테스트를 모델별로 수행한다.
4. 분석 모듈이 수익률, NAV, drawdown, 연도별 성과, 분포, 최신 포지션 및 차이 기여도를 계산한다.
5. 시각화 모듈이 분석 결과만 받아 PNG를 생성한다.
6. HTML writer가 표·그림·자동 설명을 조립하고 JSON/CSV와 함께 원자적으로 출력한다.

## 오류 처리

- factor set이 각각 `mfbt`, `origin`이 아니면 명시적으로 실패한다.
- 공통 리밸런싱 날짜가 두 개 미만이면 실패한다.
- 두 모델의 공통 수익률 날짜가 없으면 실패한다.
- 최신 포지션 날짜가 다르면 마지막 공통 날짜를 사용하고 리포트에 표시한다.
- 팩터 또는 섹터 진단 데이터가 부족하면 해당 설명만 `데이터 부족`으로 표시하고 성과 리포트는 유지한다.
- 수익률이나 비중에 비유한 값이 있으면 산출물을 쓰기 전에 실패한다.

## 검증

- 단위 테스트: 공통 기간 정렬, 비용조건 동일성, 성과지표, MDD, 연도별 재기준화, 분포 통계, 최신 포지션 분류, 기여도 합계.
- 통합 테스트: 작은 synthetic weights 두 세트로 CLI를 실행해 모든 필수 산출물과 한국어 label을 확인.
- 실제 데이터 검증: 두 기존 run root로 최종 실행하고 보고 기간, 최신 날짜, NAV 시작값, 지표의 유한성, HTML의 모든 이미지 경로를 확인.
- 기존 EMP008 모델 계산과 target weights 파일은 수정하지 않는다.

## 범위 제외

- EMP008 팩터 계산이나 최적화 로직 변경.
- 저변동성 팩터 추가.
- 결과를 PDF로 변환하거나 외부 서비스에 게시.
- 통계적 유의성에 대한 인과 주장.
