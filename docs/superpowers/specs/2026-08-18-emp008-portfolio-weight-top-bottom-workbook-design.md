# EMP008 종목비중·Active 비중 Top/Bottom 통합 엑셀 설계

## 목적

WI26과 WICS의 9개 팩터 가중치 전략에 대해 리밸런싱별 절대 투자비중 및 Active 비중 Top/Bottom 종목을 한 개의 엑셀에서 조회할 수 있게 한다.

## 기간과 대상

- 기간: 2019-12-30~2026-06-30
- 분류: WI26, WICS
- 전략: 두 실험에 공통으로 존재하는 9개 후보
- 순위 단위: 분류·전략·리밸런싱일별 각각 10개

## 시트 구성

1. `안내`: 각 순위의 정의, 실질보유 하한, 열 설명, 원본 경로
2. `후보 목록`: 분류별 후보 순위, 후보 ID, 네 팩터 가중치, 성과 지표
3. `종목비중 Top 10`: 목표 투자비중 내림차순
4. `종목비중 Bottom 10 전체`: 0%를 포함한 목표 투자비중 오름차순
5. `종목비중 Bottom 10 실질`: 목표 투자비중이 `0.0000001`보다 큰 종목만 오름차순
6. `Active Top 10`: `투자비중 - BM 비중` 내림차순
7. `Active Bottom 10`: `투자비중 - BM 비중` 오름차순

## 공통 열

데이터 시트는 다음 열 순서를 사용한다.

`분류`, `리밸런싱일`, `후보 순위`, `후보 ID`, `Size`, `12개월 모멘텀`, `영업이익 컨센서스`, `FCF/TEV`, `종목 순위`, `종목코드`, `종목명`, `투자비중`, `BM 비중`, `Active 비중`

종목코드는 문자열, 날짜는 Excel 날짜, 비중은 숫자형 백분율로 저장한다.

## 데이터 원천과 계산

- 목표 투자비중: 각 후보의 `weights/target_weights.csv`
- Active 비중: 각 후보의 `weights/active_weights.parquet`
- BM 비중: `투자비중 - Active 비중`
- 종목명: 기존 Top/Bottom 엑셀과 `raw/map.xlsx`
- 후보 순위와 성과: 기존 WI26/WICS Top/Bottom 엑셀의 `후보 목록`

Active Top/Bottom은 기존 산출물과 값 및 순서를 대조한다. 동률은 종목코드 오름차순으로 고정한다.

## 서식

- 각 데이터 영역에 자동 필터와 첫 행 틀 고정 적용
- 제목 행은 진한 남색 바탕과 흰색 굵은 글씨
- WI26/WICS는 구분 가능한 연한 배경색 적용
- Top 시트의 순위·비중은 붉은 계열, Bottom 시트는 푸른 계열 강조
- 날짜 `yyyy-mm-dd`, 비중 `0.0000%`, 성과 지표는 원본 단위에 맞게 표시
- 열 너비는 종목명과 후보 ID가 잘리지 않는 범위로 제한

## 검증

- 각 데이터 시트 행 수는 `2개 분류 × 79개 리밸런싱 × 9개 전략 × 10종목 = 14,220행`이어야 한다.
- 각 분류·날짜·전략 그룹은 정확히 10행이어야 한다.
- `BM 비중 + Active 비중 = 투자비중`을 표본 및 전체 허용오차로 확인한다.
- 기존 Active Top/Bottom 엑셀과 전 행의 종목코드·순위를 대조한다.
- 실질보유 Bottom 시트에는 `0.0000001` 이하 투자비중이 없어야 한다.
- 핵심 범위와 모든 시트를 렌더링해 잘림·빈 시트·서식 오류를 확인한다.
